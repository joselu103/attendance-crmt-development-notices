# Attendance CRMT Development Notices

This repository owns public development notices and publication artifacts for the
Attendance Teams bot; it does not own service behavior, private integration
configuration, authorization, or SQL Server access.

Before editing, read `AGENT_STATE.json` and the active `AGENT_INBOX.md`. Treat a
completed inbox directive as history. Do not publish, push, or change external
distribution settings without explicit user approval.

- [Accuracy and disclosure](docs/agent-guidance/accuracy-and-disclosure.md)
